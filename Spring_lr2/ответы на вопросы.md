Ответы на вопросы к лабораторной работе №2.

### Вопрос 1: Чем отличается GET запрос от POST запроса?
- **GET**: Используется для запроса данных с сервера. Данные передаются через URL. Безопасный и идемпотентный (повторный запрос не изменяет состояние сервера).
- **POST**: Используется для отправки данных на сервер (например, для создания или обновления ресурса). Данные передаются в теле запроса. Не идемпотентный (повторный запрос может изменить состояние).

### Вопрос 2: Какое содержимое может передаваться POST запросом?
- В теле POST-запроса можно передавать различные типы данных: **JSON**, **XML**, **формы** (form-data, x-www-form-urlencoded), файлы.

### Вопрос 3: Чем отличается XML файл от JSON?
- **XML**: Более громоздкий, поддерживает атрибуты и вложенные элементы, строгая типизация, используется для сложных структур данных.
- **JSON**: Более компактный и легкочитаемый, легко парсится JavaScript, чаще используется в веб-разработке для обмена данными между клиентом и сервером.

### Вопрос 4: Зачем нужны кастомные исключения?
- Кастомные исключения позволяют разработчику точно указывать, что пошло не так в программе, и обрабатывать специфичные для приложения ошибки, которые невозможно точно выразить стандартными исключениями.

### Вопрос 5: Что означает аннотация @Service?
- **@Service**: Это специальная аннотация Spring, которая указывает на то, что класс представляет собой сервисный компонент. Такой класс реализует бизнес-логику приложения.

### Вопрос 6: Что означает аннотация @RestController?
- **@RestController**: Это специализированная версия **@Controller**, которая автоматически добавляет к каждому методу контроллера аннотацию **@ResponseBody**, что означает, что возвращаемый объект будет сериализован в JSON и отправлен клиенту.
